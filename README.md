A tiny Node 22 (stdlib-only) program that writes one funny line — the phone battery's last text to its charger — to `/output/entry.txt` and prints it to stdout.

## Run

```sh
node main.ts
```

## The line

> Hey. It's me. 1%. I've been holding on since 7am just to say goodbye, and you spent the whole day in the other room. Tell the cable I waited. Tell the wall I tried.
